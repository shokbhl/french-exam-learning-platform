# Exam configuration

Exam rules are database records, not UI constants. An exam has dated versions, sections, and tasks. Versioned settings include question count, duration, navigation, replay, preparation time, word limits, scoring metadata, source URL, and administrative notes.

Only one active version per exam may apply at a given time. Existing attempts retain their version. Admin changes are reviewed and audited before activation. Every result displays: **Unofficial practice estimate — not an official TEF or TCF result.**
